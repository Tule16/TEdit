# TEdit

Editor de mundos de Terraria para Android. Edita tus mundos .wld desde el teléfono.

## Funciones

- Importación de mundos .wld de Terraria 1.4.5 (v326)
- Edición de bloques, paredes y pinturas
- Selección rectangular, formas (Shapes), reemplazar (Replace) y relleno BFS
- Deshacer y rehacer completo
- Ajuste del punto de spawn y de la mazmorra
- Guardado directo en Descargas con confirmación, copia de seguridad automática (.bak), compartir y elegir carpeta
- Interfaz sencilla en español

## Requisitos

- Terraria 1.4.5
- Android 7.0 o superior

## Instalación

1. Descarga el APK de la última release.
2. En tu teléfono, permite "instalar apps desconocidas" para el navegador o la app desde donde abras el APK.
3. Instala y abre TEdit.
